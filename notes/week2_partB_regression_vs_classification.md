# Week 2 Part B — Regression vs Classification

## What I Learned

In this part, I learned the difference between regression and classification in machine learning.

These are two of the most important types of machine learning problems.

The main difference is:

- Regression predicts numbers
- Classification predicts categories

---

# Regression

Regression means predicting a continuous numerical value.

The output of a regression model is usually a number.

Examples:

- predicting house prices
- predicting exam scores
- predicting temperature
- predicting salary

Example:

```text
study_hours → exam_score
```

### 2. Predicting whether a review is positive or negative

Type: Classification

Reason:

The output is a category.

Possible outputs:

- Positive

- Negative

---

### 3. Predicting tomorrow’s temperature

Type: Regression

Reason:

Temperature is a continuous numerical value.

Example output:

18.5°C

---

### 4. Predicting whether a student will pass

Type: Classification

Reason:

The output is a category.

Possible outputs:

- Pass

- Fail

---

### 5. Predicting a car price

Type: Regression

Reason:

Car price is a numerical value.

Example output:

$25000

---

### 6. Predicting if a transaction is fraud

Type: Classification

Reason:

The output is a category.

Possible outputs:

- Fraud

- Not Fraud

# My Understanding

Regression predicts numbers.

Classification predicts categories or labels.

A simple way to identify them:

- Number output → Regression

- Category output → Classification
