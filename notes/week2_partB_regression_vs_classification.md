# Week 2 Part B — Regression vs Classification

## What I Learned

In this part, I learned the difference between regression and classification in machine learning.

These are two of the most important types of machine learning problems.

The main difference is:

- Regression predicts numbers
- Classification predicts categories

---

# Regression

Regression means predicting a continuous numerical value.

The output of a regression model is usually a number.

Examples:

- predicting house prices
- predicting exam scores
- predicting temperature
- predicting salary
