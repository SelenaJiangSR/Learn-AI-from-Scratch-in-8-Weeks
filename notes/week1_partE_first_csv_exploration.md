## What Is a CSV File?

CSV stands for **Comma-Separated Values**.

A CSV file is a simple text file used to store table-like data.  
It is a common format in data work because it is easy to create, easy to read, and easy to load into Python.

A simple example of a CSV file looks like this:

```text
name,age,score
Alice,20,85
Bob,21,90
Cindy,19,88
David,22,76
Emma,20,95
